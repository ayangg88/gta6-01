SOLMAR HEAT is an original open-world crime game: explore the sun-soaked coastal city of Solmar on foot and by car, outrun the police, and run missions.
Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

The game then opens at http://localhost:8080.
